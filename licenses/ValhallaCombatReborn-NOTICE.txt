Changes to Reborn's source for Skyrim 1.7.104 (everything else is unchanged):
- built with alandtse's CommonLibSSE-NG (GPL-3.0-or-later with a modding exception), the SKSE exports are generated by the build;
- every code hook is checked before it is written (the byte at the call site must be a call into the code section), otherwise it is skipped and logged;
- the melee hit hook is found by the function it calls (Address Library id 38586) and, when another plugin already rewrote that call, attached as a chain after the code around it is verified;
- a Precision post-hit callback processes the hits Precision reports, with a 50 ms de-duplication so one blow is not counted twice;
- skill experience calls pass the four arguments the 1.7 game expects.
